# GastroVision v2.0

## Gastrointestinal Disease Prediction Desktop Application

A desktop application prototype designed for hospitals to analyze endoscopy videos for gastrointestinal disease detection. The system processes video frames using deep learning (ResNet-50) to identify diseases and highlight affected regions.

## Features

- **User Authentication**: Secure login system for medical professionals
- **Dashboard**: System overview with statistics and activity logs
- **Video Analysis**: Upload endoscopy videos or use live capture
- **Disease Detection**: AI-powered analysis using ResNet-50 deep learning model
- **Results Management**: View and export diagnostic reports
- **Modern UI**: Clean, professional interface with 3D-style design

## Prerequisites

- Python 3.8 or higher
- Windows operating system (designed for desktop deployment)

## Installation

1. Clone or download the project files
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:
```bash
python gastrovision_main.py
```

### Workflow:
1. **Login**: Enter credentials to access the system
2. **Dashboard**: View system statistics and recent activity
3. **Analysis**: Upload endoscopy video or use live capture
4. **Processing**: AI analyzes frames and detects abnormalities
5. **Results**: Review diagnostic reports and export findings
